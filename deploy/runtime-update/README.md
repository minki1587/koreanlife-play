# 공개 게임 자료 자동 점검

매주 화요일 00:00 UTC(한국 오전 9시)에 이 공개 저장소가 공식 공공데이터포털을 직접 점검합니다. 비공개 개발 저장소와 같은 공식 원천을 병렬로 수집하며 비공개 저장소를 읽거나 인증 토큰을 복사하지 않습니다. GitHub가 제공하는 해당 저장소의 `GITHUB_TOKEN`만 커밋과 Pages 배포에 사용합니다.

자동 변경 허용 범위는 15119096·15119098·15122500의 직업 분류 확인, 537개 직업 학력분포 원값, 제공되는 10개 직업 임금 중앙값·사분위, 출처 수정일·해시입니다. 확인한 공개 페이지와 카탈로그 양쪽이 **무료·이용허락범위 제한 없음**이어야 파일을 받습니다. 원본 CSV/ZIP과 권리 페이지는 실행 중 임시 폴더에만 존재하고 공개 저장소나 Actions 아티팩트에 업로드하지 않습니다.

537개 직업의 코드·이름·분류, 원본 열 구성, 자료 범위, 무료·이용조건이 변경되면 자동 반영하지 않고 작업을 실패시킵니다. 기존 공개 게임과 검토된 전문직 자격·학력 경로, 게임 임금·능력·위험 모형을 보존합니다. 출생은 승인한 **2025년 통계 구역**, 사망률은 승인 스냅샷을 유지하며 새 통계 연도를 자동 편입하지 않습니다. 나머지 국내 자료를 모두 자동 게임에 반영한다고 주장하지 않습니다.

`site/runtime-update-status.json`은 마지막 성공 점검·실제 자료 변경 시각과 범위를 공개합니다. 실패 기록은 Actions 실행 결과에서 확인하며 마지막 정상 게임을 유지합니다. 변경 없는 성공 점검은 `lastCheckedAt`만 새로 기록하고 `lastUpdatedAt`을 갱신하지 않습니다. 최초 배포 상태는 `not-yet-run`이고 점검 시각은 null입니다.

```bash
python -m unittest discover -s deploy/runtime-update -p 'test_*.py' -v
python deploy/runtime-update/update_runtime.py --dry-run
```

정본 개발 환경에서 기존 승인 수집 데이터만 이용하는 네트워크 없는 점검:

```bash
python web/deploy/runtime-update/update_runtime.py --site <export>/site --marker <export>/.koreanlife-pages-export.json --offline-data-dir data --dry-run
```

오프라인 자료 인자는 `--dry-run`에서만 허용됩니다. 게시 실행은 새로 받은 공식 페이지의 이용조건을 확인합니다. 변경 없는 값도 원본 해시, 수치, 분류판 일치 검증을 통과해야 합니다.

공개 자동 갱신 후 예전 정본으로 수동 배포하여 관측값이 되돌아가는 것을 막기 위해, export 도구는 공개 상태의 원본 해시와 정본을 비교합니다. 공개에 더 새로운 원본이 있으면 먼저 비공개 원본을 다시 수집·검증하여 동기화해야 합니다. 같은 원본이라면 최신 점검 상태를 정본에도 보존합니다.

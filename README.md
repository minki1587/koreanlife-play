# Korean Life

[Play the game](https://minki1587.github.io/koreanlife-play/)

This repository contains the public browser deployment only. The collector and research sources remain in the private development repository.

Source attributions and model notices are available in the game footer.

Approved observed career data are checked every Tuesday at 09:00 Asia/Seoul. The public updater reads only three official public sources; private raw files are never published. Birth geography remains the reviewed 2025 snapshot and mortality is not updated automatically. See [updater scope](deploy/runtime-update/README.md).
